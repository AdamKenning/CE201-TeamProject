# User Stories MD (Concise version)
## Explanation and example
- ### User Story Structure
  - User stories are often expressed in a simple sentence, following a simple structure.
    - “As a **persona**, I **want X**, **so that Y**.”
  - Explanation of Parts
    - As a **persona**: Defines the user role, like "parent" or "caregiver."
    - I **want X**: Specifies the action or feature the user needs to use "X".
    - **So that Y**: Explains the purpose or value this feature provides "Y".
  - This structure ensures that each user story aligns with the software’s goal of supporting child health management
    and providing actionable insights to users.
- Source : https://www.atlassian.com/agile/project-management/user-stories
## User Stories 
1. Tracking and logging routines
   - As a **parent and caregiver**, i want to **log feeding, sleep, diaper changes, and medication schedules** so that i can **track patterns to track my child health**
2. Growth and development monitoring
   - As a **parent** i want to **track my child's height, weight etc over time** so that i can **monitor their growth to compare it to standard benchmarks**
3. Insights and alerts
   - As a **parent and caregiver**, i want to be **notified about changes in routines or health** so that i can identify potential issues early
4. Data sharing and reports
   - As a **parent and caregiver**, i want to **generate summaries or detailed reports** so i can **easily share health updates with healthcare providers** during medical visits
5. Interactive visual summaries
   - As a **parent**, i want **simple interactive graphs and visual summaries** to **quickly understand development trends**
6. Health alerts
   - As a **school nurse or caregiver**, i want **to be informed about students with high-risk conditions or medication needs** so that i can **respond quickly during health incidents**
7. Anonymised research data
   - As a **student and researcher**, i want **access to anonymised data** so that i can **study general populace trends**
8. Multi-Device support
   - As a **Parent or caregiver**, i want to **use the app on multiple devices** so that i can **manage my child on the go**
9. Secure data handling
   - As a **parent**, i want assurance that my child data is **securely stored and anonymised** so i can **protect their privacy**
   - As a **User**, i want **strong password encryption and secure login methods** so that **my account and personal data remains safe**
10. Accessibility and Usability
    - As a **user with accessibility needs** i need the app to include:
      - **Themes** like sepia and dark mode **to reduce eye strain**
      - **Clear, large fonts** for **easier reading** - dyslexia
      - **Large buttons** for **easier navigation with motor impairments** - parkinson's
    - As a **user with colour blindness** I need the app to include **Colour profiles** for **easier viewing**
      - Protanopia - Red blind
      - Deuteranopia - Green blind
      - Tritanopia - Blue blind
      - Achromatopsia - Complete colour blindness
