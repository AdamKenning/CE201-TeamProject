CHAWTS Package Breakdown

Overview
    This package contains the functionality of CHAWTS (Child Health and Well-Being Tracking Software).

Structure
    ChawtsApp.Java
        What is run at the start, sets up the window for the application, and links various aspects such as the ChawtsDisplay and ChawtsData.
    ChawtsDisplay.Java
        Handles presenting the software graphically to the user, as well as managing user inputs and knock on functionality e.g. opening a menu.
    ChawtsData.Java
        Handles the raw data used to run the software, including opening, processing (cleaning), storing retrieving etc.
